# Changelog

All notable changes to WinMate. The format follows [Keep a Changelog](https://keepachangelog.com/),
versions follow [Semantic Versioning](https://semver.org/). The current version is in [`VERSION`](VERSION).

## [Unreleased]

## [2.2.0] - 2026-09-14

### Added
- Script modes: **install, update and uninstall**, plus a **dry run** that only reports what would happen.
- **Undo script** after every install run (removes only newly installed apps), run records and logs in
  `%LOCALAPPDATA%\WinMate`.
- Optional **System Restore point**, **proxy** setting, pending-reboot check and a restart prompt at the end.
- **Version pinning** to the versions recorded by the weekly catalog check (winget, Chocolatey).
- **Command-line tool `winmate.ps1`** with `-List`, `-Search`, `-Apps`, `-Bundle`, `-ProfilePath`, `-DryRun`,
  `-Mode`, `-ExportScript`, `-Logs` and `-Verify`.
- **Profiles**: export and import the selection as JSON on the website (also accepted by the CLI).
- **winget import file** download (`winget import -i`).
- **Security page** (EN/DE) with threat model, verification steps and known limits; `SECURITY.md`.
- **Package sources** on every app page: manifest links and verified versions; also in `apps.json`.
- Public **CI** (build, site check, reproducibility check, Windows engine tests), weekly **catalog check** that
  proposes version updates and opens issues for broken packages, **release workflow** with build provenance.
- `build-info.json` with version, commit and file hashes; engine published as `engine.ps1`.
- Contribution guide, code of conduct, issue and pull request templates, roadmap, catalog policy.
- Header button to turn animations off.

### Changed
- Builds are reproducible: dates come from the last commit instead of the clock.
- Scripts carry a version header and the engine SHA-256; config and engine are marked for verification.

### Fixed
- winget installs of already installed apps are reported as updates and never end up in the undo script.

## [2.1.0] - 2026-09-14

### Added
- Retro arcade design with animated background and pixel-art icons.
- 16 bundles in three groups with a selection dialog; manual picks tracked separately.
- Keyboard shortcuts, `/about/` page, 29 new apps, category "Self-Hosting & Backup".

### Changed
- Site URL moved to `winmate.baba537.workers.dev`.

## [2.0.0] - 2026-09-13

### Added
- Complete rebuild: static EN/DE site generated by `build.py`, 344 verified apps, real app icons,
  single administrator prompt, per-app/category/bundle pages, `llms.txt`, `apps.json`.

## [1.0.0] - 2026-05-29

- First version: 181 apps, script download as ZIP.
